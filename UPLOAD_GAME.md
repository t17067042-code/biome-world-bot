# Upload the game (one time)

1. Open https://github.com/t17067042-code/biome-world-bot
2. Click **Add file** → **Upload files**
3. Upload `static_game.html` (from the project zip or attachments)
4. Commit
5. Railway will redeploy automatically
6. Open https://web-production-3ac70.up.railway.app/sp

Also set variable:
`MP_PUBLIC_URL=https://web-production-3ac70.up.railway.app`
